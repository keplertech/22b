# RTL Examples

Place each RTL example under `examples/rtl/<design>/`, with its specification,
source, test inputs, elaboration settings, expected behavior and reproduction
commands. Keep generated outputs under `runs/`, outside the versioned example.

No RTL benchmark has been added yet. Use the [RTL skill](../../flow/rtl/SKILL.md)
for the workflow; [backend/GCD](../backend/gcd/README.md) is the first concrete
example in this repository.
